# 课件勘误（做内容比对时发现的）

> 这份文件只记**课件本身**的错误与模糊之处。
> **判分时要注意**：讲解里"照抄课件"的数值错误**不应算作讲解者的错误**（MQI 编码 12 判的是教学者讲错）；
> 但**应当被标出来**——用户提供的 L7 system prompt 第十六节要求的正是这个：
> 「发现课件存在错误或模糊时，不要偷偷'修正'，要明确标记」。

---

## 1. ★ 编码 12 判分时的典型误伤案例（AIAA 2711）

**位置**：`l06-p05`（Lecture 6 · 反向传播与自动微分）

**课件原文**：

> ① if $f'_e(\vec{z}^{(l)}) < 1 \Rightarrow L \uparrow$, $\delta^{(l)} \to 0$
> (consider $0.9^{1000} = 4.3 \times 10^{-5}$)

**问题**：

| 表达式 | 正确值 |
|---|---|
| $0.9^{1000}$ | **1.748 × 10⁻⁴⁶** |
| $0.99^{1000}$ | **4.317 × 10⁻⁵** |

课件写的是 $0.9^{1000}$，但给的数 $4.3\times10^{-5}$ 对应的是 $0.99^{1000}$——
**指数写错了（0.99 写成了 0.9）**，差了 41 个数量级。

**影响**：

- 忠实复述课件的讲解（含本项目的两段）会被误判为"内容错误"。
  → **本轮 MQI 盲评就发生了这一次误判**，已核实并纠正（该项本应记 0）。
- 更要紧的是：**任何"忠于课件"的 agent 都会继承这个错误**。
  这恰好说明"**课件有错就标出来**"这条约束（`docs/09` L12）不是可选项。

**处置**：
- 判分口径写明：**照抄课件的数值不算讲解者错误**；
- 但讲解若**自己算出**数值且算错，**要算**（见下条）。

## 2. 模型的"假装算过"模式（这不是课件的问题，是生成的问题）

**位置**：KL 散度那一问（L09）

**课件**：`l09-p03` 给的是**填空题**——`KL(P, Q) = ___ (nat)`，**没有给数值**。

**讲解**：自己补了一套算例，并以"执行结果"的口吻写进代码注释：

```python
H_PQ = -sum(p * math.log(q) for p, q in zip(P, Q))
# 执行到这里 H_PQ ≈ 1.3342
```

**实际值**（我独立复算）：

| 量 | 讲解写的 | 正确值 |
|---|---|---|
| $H(P,Q)$ | 1.3342 | **1.2629** |
| $KL(P,Q)$ | 0.3045 | **0.2332** |

**为什么单独记这条**：两个值**同时偏高同一个数（+0.0713）**，
且它们是以 `# 执行到这里 …` 的形式断言"实际计算结果"——
**不是笔误，是把没算过的数当成算过**。

**为什么危险**：
- 它骗得过阅读者（包括人）：格式、公式、思路都对，只有数字是编的；
- **只有逐行代入复算才能发现**——本轮是盲评判者代进去算出来的。

**处置建议**（**尚未落地，待用户裁决**）：
- 给"详细"档加一条：**给出算例时必须真的代进去算，或明确标出"未验算"**；
- 这与用户给的 L7 prompt 第十六节（不许偷偷修正 / 不许猜）同向，
  但**是否需要落地要先问用户**——它属于"新增约束"，按总原则要先说清必要性。
