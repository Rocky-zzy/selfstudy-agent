# 从「L7 自学讲义」system prompt 里提取的讲解模式

> **来源**：用户 2026-09-21 提供的另一个项目的 system prompt（**全文见 §附录**）。
> 该 agent 按它产出的文档，**用户评价"我觉得很不错"**。
>
> **这份材料的证据地位（必须写清，不得含糊）**：
> - 它是一个**同行/同用户手上的实战件**，有**用户本人的判断**支持——这是**真实证据**，不是我的直觉。
> - 但它**不是实验结论**：它是**单用户、单项目、未与替代方案对照**的观察（错题本 M5/M6 的口径适用）。
> - 因此本文给每条机制标三种状态：**Ⓐ 本项目已有出处** / **Ⓑ 有文献支持的通用做法** / **Ⓒ 仅新档位采自该 prompt，本项目尚无验证**。
> - **采自 Ⓒ 的东西，落地时必须写成"按该案例先做一版"，不能写成"已验证有效"。**
>
> ⚠️ 本文只做**提取**。融入是下一步，且须用户逐项批准（见 §五）。

---

## 一、第一件事：形态差别，不是技巧差别

这是最关键的一条，**不先说清会把后面的都融错**。

| | L7 项目 | 我们现在 |
|---|---|---|
| 产物 | **一份自足的 `.md` 讲义**，学生**完全不提问**也能学会 | **一问一答**的一次讲解 |
| 学生角色 | 读者，从头读到尾 | 提问者，一次问一个点 |
| 目标 | 把整讲**重建**成一堂课 | 把**他问的那个点**讲到能往下走 |
| 长度 | 一整个 Lecture | 600–800 字（概览）/ 不限（详细） |
| 副作用 | 讲义可反复读、可当复习材料 | 对话结束就散了（我们靠 `ratings.jsonl` 存原文补救） |

**所以**：L7 里很多"好东西"是**文档形态**才成立的（知识地图、章节结构、Cheat Sheet、自足性检查）。
**不能整包塞进我们的 prompt**——那会把"一次讲解"变成"一篇文章"，反而违背你之前
「**输出不一定一次要输出完一整章**」的要求。

**可融入的是它背后的教学动作，不是它的文档骨架。** 下面按这个区分逐条列。

---

## 二、逐条提取

### L1 ★ 自足的完整讲义（整讲重建）

- **L7 怎么做**：两轮处理（Pass 1 内容抽取 → Pass 2 教学重建），产出自足文档；
  自检清单含「**学生不看 PPT，只看这份 md，能否理解**」。
- **状态**：Ⓒ（形态层面）
- **对我们的含义**：这是一条**产品级选项**，不是 prompt 微调。
  可以作为**第四档讲法**（如 `lecture`：整讲讲义），与现有三档并存。
  但**必须你拍板**，因为它和"问答式、一次一个点"的定位冲突。
- **不建议**现在做。

### L2 ★ 有结构的例题（Worked Example 流水线）

- **L7 怎么做**：`Problem → 已知什么 → 求什么 → 该用哪个概念 → 为什么用它 →
  Step 1/2/3 → 最终答案 → 为什么这个答案合理`；
  并明确「**不要默认学生已经知道第一步该做什么**」。
- **状态**：Ⓑ 有文献支持（worked examples；`docs/03` §六 也已有"讲 why"的相关判据）；
  ⚠️ **worked examples 的原始文献我仍未取得**（ACM / Cambridge 付费墙，见 `docs/08` §2.3）。
  能说的是：**本项目已有出处指向同一方向**（`docs/03` 机制二：例子与非例子成对、给对比案例）。
- **对我们的含义**：我们现在的"详细"档有"逐行注释"，**但没有"为什么选这个方法"**。
  这是**当前差距最明确、最容易补**的一条。→ **建议第 2 步就做这个。**

### L3 ★ 每个概念配"常见的坑"

- **L7 怎么做**：主动指出学生最易犯的错误（"很容易把 A 和 B 混淆，因为……"）。
- **状态**：Ⓒ（L7 prompt 有，我们**完全没有**）
- **依据方向**：与 MQI 编码 12（错误）与 4（sense-making：**找反例**）同族；
  `docs/03` §六 也已有"合适时给一个反例或边界情形"。
  → 可以看作**已有判据的落地化**，不是新造。
- **对我们的含义**：**低成本、高感知**。已实测的失败正好印证：
  「很容易把 `.loc` 和 `.iloc` 混淆」这类内容，用户是明确要的。

### L4 ★ 停顿思考（Pause & Think，带答案）

- **L7 怎么做**：`> **先自己想一下：为什么这里用 X 而不是 Y？**` 紧接着
  `> **答案：……**`；明确「不能停下来等回答」。
- **状态**：Ⓐ **这正是你 2026-09-19 定的**：「设问，**不要要求一定要用户作答**」。
  → L7 只是把同一件事写得更规范。**我们已经实现了**（详细/追问档的"设问"约束）。
- **对我们的含义**：可以把 L7 的**措辞**借来（"先自己想一下……答案：……"），
  让输出更稳定。属**微调**。

### L5 主动回忆（Quick Check + 同一文档内给答案）

- **L7 怎么做**：每章末 2–5 题，覆盖 What/Why/How/Application/Comparison；
  答案放在 `<details>` 折叠块里，**同一文档内**。
- **状态**：Ⓑ 检索练习 / 测试效应是教育心理学里证据较稳的做法；
  ⚠️ **具体效应量我这次没取得原文**，所以**不引数字**。
- **对我们的含义**：**在问答形态下很别扭**——每次讲解都附 3 道题会打断节奏、撑长篇幅。
  更适合放在"整讲讲义"档（L1）。**建议暂缓**。

### L6 使用条件与**不该用**的情况

- **L7 怎么做**：`When to Use` + **明确什么时候不该用**。
- **状态**：Ⓒ（我们只有 MQI 编码 4 的"合理性/反例"沾边）
- **对我们的含义**：与 L3 同一类，成本低。**可并入第 2 步。**

### L7 概念之间的"连接"显式化 + 对比表

- **L7 怎么做**：`A → 导致/依赖/限制 → B → 产生 → C`；容易混的做成
  `Definition/Purpose/Input/Output/When to use/Common mistake` 六行对比表。
- **状态**：Ⓒ，但方向上有 `docs/03` 支撑：**"联结/多表征"是所有量表里信度最低的一维**
  （KP2022 = 0.64、Thurm C2 = 0.81）→ **说明它难，也说明它值钱**。
- **对我们的含义**：用户实测里"两段都读不出差别"的抱怨，很可能就是因为**缺连接**。
  但有**一个硬约束**：你现在用的是"仅命中页/整讲"喂料，
  **连接只能在课件提到的概念之间建立**，不能替课件发明关系。→ 需写成约束。

### L8 拆解教学 + 前置知识短复习（Prerequisite Refresher）

- **L7 怎么做**：把复杂概念拆成小块；依赖前置知识时先给**很短一段**刷新，
  且明确「**不要为了补背景而跑题**」。
- **状态**：Ⓐ 已在 `docs/03`：机制一（segmenting）+ 机制二（pre-training）+ 机制三（适配已有知识）。
- **对我们的含义**：**已有，但没落地到 prompt**。→ 建议并入第 2 步（一句话约束）。

### L9 公式的讲法（Formula → Variables → Relationship → Intuition → Derivation → Example → Interpretation）

- **L7 怎么做**：禁止"经过推导可得……"，必须解释关键步骤为什么成立。
- **状态**：Ⓐ `docs/03` §六 的核心判据（MQI 编码 3：讲 why，步骤描述不算解释）+
  编码 13（记号卫生）**已经覆盖**。
- **对我们的含义**：**我们已有判据，但显然没落地**——实测最一致的抱怨就是公式/符号。
  这**不全是 prompt 问题**（一半是渲染问题，见 §三）。

### L10 "读图"（横轴/纵轴/节点/箭头/先看哪里/结论）

- **L7 怎么做**：不许写"Figure 3 shows..."；要求解释图的每个视觉元素与结论。
- **状态**：Ⓒ（我们**完全没有**）
- **对我们的含义**：**这份 NLP6 素材正好大量依赖图**（p7 的 CFG 定义就在图里）。
  但有前提：**图的内容已被我们转写进文本**（`temp_material/nlp6/README.md`），
  所以模型是"读转写文本"而不是"读图"，**这会限制它读图的可靠性**。→ 需诚实标注。

### L11 课件内容 vs 补充解释，严格区分

- **L7 怎么做**：Course Content / Supplementary Explanation 分开标；
  冲突时**以本课程课件为课程事实**；**不许把外部知识伪装成课件讲过的**。
- **状态**：Ⓐ **正是我们的"只讲课件里有的"**（详细档约束 9），
  但 L7 的写法更细：它**允许补充**，只是要求**标出来**。
- **对我们的含义**：我们现在的约束是"**不许引入课件外内容**"（更严）。
  你 2026-09-19 的要求也是「**不要超出课件内容**」，**所以维持更严的版本**。
  但可以借 L7 的**冲突处理**：课件自相矛盾时**明确标记**而不是悄悄修正。

### L12 发现课件有错/模糊时，标记而不是偷偷改

- **L7 怎么做**：固定格式输出「课件写法 / 问题 / 更准确的理解」，不能确定就不猜。
- **状态**：Ⓒ，但与 `docs/03` MQI 编码 12（四级严重度）、编码 14（同一概念给出冲突定义）**同族**。
- **对我们的含义**：**直接对应我们转写素材的已知缺陷**
  （`temp_material/nlp6/README.md`：公式符号偶有偏差）。
  加这条能让模型把这些偏差**报出来**，而不是当成课件事实讲给学生。**价值高。**

### L13 知识地图（开头给整讲结构）

- **L7 怎么做**：讲义开头一张树状 Knowledge Map。
- **状态**：Ⓒ（文档形态的产物）
- **对我们的含义**：问答形态下**只能作为"概览"档的一部分**（我们已有"只给骨架"），
  不需要新机制。**跳过。**

### L14 语言风格：英文术语 + 中文解释

- **L7 怎么做**：首次出现的术语给 `**Bias（偏差）**`，之后直接用英文。
- **状态**：Ⓒ 但**与你实测反馈方向一致**（你说过分歧在于"术语密度"）。
- **对我们的含义**：**低成本、明确**。建议并入第 2 步。

### L15 两轮处理 + 最终质量自检清单

- **L7 怎么做**：先抽取、不输出；再重建；输出前按 10 项自查。
- **状态**：Ⓒ（它是 agent 的工作流，不是学生看到的内容）
- **对我们的含义**：我们的生成是**单次调用 + 12 条约束**，
  没有"先抽取再重建"的两阶段。**这与 `docs/04` §九 里状态仍为"待证明"的
  「两段式生成 + critic」是同一件事**——**不能因为 L7 这么做就解禁**，
  那正是总原则要防的（把同行做法当必要性证明）。

## 三、顺带确认的一件事：渲染问题不是 prompt 能解决的

用户**连续三次**反馈（9-18、9-21 ×2）：
> 「代码块和字体等没有做渲染」（9-18）
> 「公式没渲染处理，一堆杂乱的符号根本看不懂」（9-21）
> 「没有公式和符号的渲染，看起来很费解」（9-21）

**现在的界面渲染器只处理**：围栏代码块、行内代码、标题、列表。
**不处理 LaTeX**：`\(V\)`、`\vec{x}_0`、`(\Sigma \cup N)^*` 会被当普通文字显示。

→ 实测证据：命中的那句「**公式没渲染处理，一堆杂乱的符号根本看不懂**」
对应的正是 `l01-p07` 那种 `\(...\)` 密集的**数学/形式定义**内容。
**这解释了为什么"详细"档在 NLP6 的 CFG 分区只拿到 4 分**：
内容对了，但**读不下去**。

**约束条件**（不得违反）：
- 本机**没有**可离线的 KaTeX/MathJax（已查：npm 缓存与 DSH checkout 里都没有）。
- 项目惯例是**不引 CDN**。
- 所以要么①把 KaTeX 下载到本地随项目分发，要么②自己写一个**有限**的数学渲染器
  （只覆盖我们课件里实际出现的记法）。

**这是独立于本文的一步**，且需要你选路线。**不在这轮做。**

## 五、建议的融入步骤（**一步一停，等你点头**）

- **第 2 步（最小、最稳）**：只改 `detailed` 档的 prompt，加 L2/L3/L6/L8/L12/L14 六条，
  **不动产品形态、不动两条件共用的原则**。做完拿 NLP6 的 CFG 分区再测一轮。
- **第 3 步**：加 L7（连接 + 对比表）与 L10（读图），并写明"不能替课件发明关系"的硬约束。
- **第 4 步（需你单独拍板）**：L1 整讲讲义档（产品级）；L9 的公式渲染（技术路线二选一）。
- **始终不做**：L15 两阶段生成（待证明）；L5（暂缓）。
