## 节点

### `abelian_group` — Abelian 群

- **类型**：概念
- **出处**：l01-p02
- **易错点**：
    - 漏掉封闭性（运算结果必须还在集合里）
    - 把 (R, ·) 当成群——0 没有乘法逆元（课件正是用这个反例说明）

### `vector_space` — 向量空间

- **类型**：概念
- **出处**：l01-p02
- **前置**：abelian_group（Abelian 群）
- **对比对象**：affine_space（仿射空间 L = x₀ + U）
- **易错点**：
    - 以为「能加能乘」就够了，漏掉封闭性与分配律那几条
    - 忘了 (V, +) 本身必须是 Abelian 群

### `matrix_vector_form` — 线性映射的矩阵形式 y = Wx + b

- **类型**：概念
- **出处**：l01-p01
- **前置**：vector_space（向量空间）
- **易错点**：
    - 把 W 的下标记反（课件约定 W_ij 是 x_j → y_i 的权重）
    - 把 b 当成另一个权重向量——课件把它写成「从常数 1 到 y_i 的权重」

### `linear_combination` — 线性组合

- **类型**：概念
- **出处**：l01-p03
- **前置**：vector_space（向量空间）
- **上位**：vector_space（向量空间）

### `linear_independence` — 线性无关 / 线性相关

- **类型**：概念
- **出处**：l01-p03
- **前置**：linear_combination（线性组合）
- **上位**：vector_space（向量空间）
- **对比对象**：spanning_set（张成集 / 生成集）
- **易错点**：
    - 把「无关」理解成「彼此没关系」
    - 漏掉条件：必须是「只有平凡解」（λ 全为 0）才算无关

### `spanning_set` — 张成集 / 生成集

- **类型**：概念
- **出处**：l01-p03
- **前置**：linear_combination（线性组合）
- **上位**：vector_space（向量空间）
- **对比对象**：linear_independence（线性无关 / 线性相关）
- **易错点**：
    - 以为「能张成」就等于「线性无关」

### `linear_mapping` — 线性映射 φ: V → W

- **类型**：概念
- **出处**：l01-p04
- **前置**：vector_space（向量空间）、matrix_vector_form（线性映射的矩阵形式 y = Wx + b）
- **上位**：vector_space（向量空间）
- **易错点**：
    - 把它当成「任意从 V 到 W 的函数」
    - 只说「保持结构」而不验证 λx + ψy 这条定义式

### `rank` — 秩 rank(W) 与满秩

- **类型**：概念
- **出处**：l01-p04、l01-p05
- **前置**：linear_mapping（线性映射 φ: V → W）
- **对比对象**：kernel_image（核与像（null space / column space））
- **易错点**：
    - 把 rank 当成矩阵的尺寸（rank = min{m,n}，不是 m×n）
    - 把升维/降维的方向搞反（rank = n < m 是升维，不是降维）

### `kernel_image` — 核与像（null space / column space）

- **类型**：概念
- **出处**：l01-p06、l01-p07
- **前置**：linear_mapping（线性映射 φ: V → W）
- **上位**：linear_mapping（线性映射 φ: V → W）
- **对比对象**：rank（秩 rank(W) 与满秩）
- **易错点**：
    - 把 kernel 与 image 的所属空间搞反（ker ⊆ V，im ⊆ W）

### `rank_full_rank_cases` — 满秩时的三种情形（同维 / 升维 / 降维）

- **类型**：程序性
- **出处**：l01-p04、l01-p05
- **前置**：rank（秩 rank(W) 与满秩）
- **上位**：rank（秩 rank(W) 与满秩）
- **易错点**：
    - 把升维/降维的方向搞反（rank = n < m 是升维，不是降维）
    - 把「同维」当成「同一个空间」——课件说的是用不同坐标表示同一个向量

**★ 子目标（3 步）**——依据 Morrison 等 2020：无反馈条件下**给标签**优于让学生自己生成；按 Catrambone 1995/1998，标签写**功能/目的**、不绑符号。

| # | 子目标标签 | 课件原文对应 | 这一步在做什么 |
|---|---|---|---|
| 1 | **判断满秩** | `rank(W~) = min{m, n}` | 先确认 W 达到满秩，否则下面三种情形都不成立 |
| 2 | **比维度定方向** | `① rank = n = m；② rank = n < m；③ rank = m < n` | 比较 n（输入维）与 m（输出维），决定是同维、升维还是降维 |
| 3 | **读用途** | `② upsampling / handling data in a lower dimension in a higher dimension；③ downsampling / dimensionality reduction` | 升维是「在更高维里处理低维数据」，降维是「取高维数据最重要的视角」 |

> ⚠️ **课件没交代的地方（讲解若补上，属补充解释而非课件内容）**：
> - 第 1 步「判断满秩」：课件给了定义但没强调「必须先满秩才能分类」。
> - 第 3 步「读用途」：课件只给了用途短语，没解释为什么升维有助于处理低维数据。

### `matrix_form_derivation` — 从分量式到矩阵形式的合并

- **类型**：程序性
- **出处**：l01-p01
- **前置**：matrix_vector_form（线性映射的矩阵形式 y = Wx + b）
- **上位**：matrix_vector_form（线性映射的矩阵形式 y = Wx + b）
- **易错点**：
    - 以为矩阵形式是另一套东西，而不是分量式的紧凑写法

**★ 子目标（3 步）**——依据 Morrison 等 2020：无反馈条件下**给标签**优于让学生自己生成；按 Catrambone 1995/1998，标签写**功能/目的**、不绑符号。

| # | 子目标标签 | 课件原文对应 | 这一步在做什么 |
|---|---|---|---|
| 1 | **写出每个输出的分量式** | `y_1 = W_11 x_1 + W_21 x_2 + W_31 x_3 + b_1（y_2、y_3 同理）` | 先把 y 的每个分量写成 x 各分量的加权和再加偏置 |
| 2 | **把权重按列排成矩阵** | `列向量 [W_11, W_12, W_13]^T 对应 x_1 的权重` | 注意课件把 x_j 的权重排成 W 的**第 j 列**（这正是行下标为 j 的原因） |
| 3 | **合成紧凑式** | `y = W x + b（compact form）` | 矩阵乘 x 一次算出全部输出的加权和，b 单独加 |

> ⚠️ **课件没交代的地方（讲解若补上，属补充解释而非课件内容）**：
> - 第 1 步「写出每个输出的分量式」：课件直接列出三行，没说明为什么要先展开。
> - 第 3 步「合成紧凑式」：课件未说明这种「按列堆权重」的排法与「按行做内积」是同一件事。

### `affine_space` — 仿射空间 L = x₀ + U

- **类型**：概念
- **出处**：l01-p07
- **前置**：vector_space（向量空间）
- **上位**：vector_space（向量空间）
- **对比对象**：vector_space（向量空间）
- **易错点**：
    - 以为仿射空间也是向量空间（漏掉 x₀ ∉ U 这个前提）
    - 混淆 support point（x₀）与 direction space（U）的角色

### `affine_mapping` — 仿射映射 φ'(x) = a + φ(x)

- **类型**：概念
- **出处**：l01-p08
- **前置**：affine_space（仿射空间 L = x₀ + U）、linear_mapping（线性映射 φ: V → W）
- **上位**：affine_space（仿射空间 L = x₀ + U）
